## Goals

1. `brokkr run --recipe R --enter <gate> [--continues <run>]...` for any recipe, admitted or refused when the recipe and the entry are compiled, before a run id is minted or an event is written.
2. A run entered at `verify` over a finished branch reaches `SHIP-COMPLETE` with no intake, design or first-implement seat, proven on a synthetic recipe and repository.
3. The journal records, typed, the entry and the runs continued; the run view names them, each continued run led by its title, `brokkr_view::title` of its feature, with the whole feature kept in its parts; the gate vouches the branch and names the chain.
4. Nothing skips verification or review that today's tables do not already skip: review stays unavoidable from wherever a run begins, and a work phase is reached in an entered run only by a return.
5. No ordinary run's seat input, manifest, digest witness or admission moves by the engine change; its `run/started` gains the one key `phases` (D19), and nothing else. One recipe's own data moves one order: `landing` lists `classify` first, its `tables` and `bundles` witness rows move, and its seats after `classify` read that phase's result by the compiled order (D36's F3, D37, D38).

## Decisions

### DD1 — The flag, not the overlay

`brokkr run --enter <phase>`, with `--continues <run>` repeatable, declared on `brokkr run`'s own arguments (D18). The composed overlay was weighed and not chosen, and decision 0094 records why among what it set aside: an overlay's `initial` cannot be told from a recipe's own first phase, so the compiler could not refuse a work-phase entry without a second marker; a recipe is static data and cannot name the runs one re-drive continues; and an adopter would write one overlay per recipe and gate, each restating one word, the copy ruling 5 forbids. The overlay road stays what it is, a recipe's own `initial` (`landing`, `review-first`), and an entry composes over it.

### DD2 — The admission is one function in one new module, run at two moments, and it returns nothing but its refusal
