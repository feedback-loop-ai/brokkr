## One commission fact the code contradicts

The commission's item 7 asks the guides to say that, after the upgrade,
every Linux writer Brokkr cannot box refuses on every run. The merged code
does not do that. The operator's ruling of 2026-10-29 on U9b1's fourth run
superseded that clause, and `engine/broker/exclusion.rs` states the rule as
built: the refusals apply where evidence is at stake, and "a run with
nothing at stake admits a writer Brokkr cannot box". The guides publish the
code's rule. They also say what the code does refuse on every run: a boxed
writer whose reach covers the coordination root (U9b1a).
