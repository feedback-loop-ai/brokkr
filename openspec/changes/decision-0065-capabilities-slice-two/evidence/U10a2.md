The findings as run 1 wrote them:

**F1, row 21, spec against ruling.** MB4's scenario says a secret-free
dialect naming a missing store refuses before lookup and makes no store. In
practice `engine/boxed.rs:246` `make_store` (operator ruling 2 of 2026-10-23)
makes a missing store for every boxed seat before the broker sees it, and
every MCP seat is boxed (MB2). So the broker's missing-store refusal is
reached only when the store goes missing after the engine's admission, and
the test proves exactly that. Option (a), recommended: amend the scenario to
"a store missing at dispatch is made empty by the engine; one gone between
admission and delivery refuses by MB3's identity cause". Option (b): exempt
secret-free plans from `make_store`, a production change that weakens
nothing but moves ruling 2.

**F2, row 29's removal.** Adding a host bind to the server argv is caught
first by the bootstrap's own mount check (Establishment). The test fails on
that cause, and its probe line is never reached under any single removal. A
removal that reaches the probe joins two, the extra bind and the bootstrap's
mount check, as U9b1b's private-directory removal did (U9b1b.md:194). That is
recorded here and was not run.

**F3, rows 12 and 11 not reachable by an unprivileged fixture.** Row 12's
predicates need multiply-linked root-owned support files with chosen
owner, mode, ACL or uid mapping, and an unprivileged seat cannot make those.
Row 11's 1,000,000-entry bound needs about a million files in a package, and
its 65,536-mount bound needs mounts, which need privileges. So does its
hard-linked user-owned library under `/usr/local`. Their proofs stay at the
seams (U6c5a–U6c5c). Option (a), recommended: record them as host evidence,
pending on a privileged runner, as H5 is. Option (b): a production seam that
lowers the bounds, which ruling 6 refuses without a consumer.

**F4, row 25 not repaired.** Replacement-attempt separation holds by
construction, since every attempt is a fresh box. The only removal that
reaches it is U9b1b's joint one (one shared bind for both private
directories, with the bootstrap's `dir.empty`, `fresh` and `each` removed).
This visit did not build a dispatch test with that removal.

**F5, 8.2's init wrapper.** Init writes compiled-in adapters
(`cli init/adapters.rs`) and compiles them at once. No shipped or fresh
scaffold has an unsupported or missing assessment, so an SI2 cause inside
"scaffolded bundle failed to compile" is unreachable without a mutation.
M8a shows it whole. The serving edge's refusal (M8c) is likewise unreachable
from shipped scaffolds and is bound in protocol's suite. Ruling owed: (a),
recommended, accept 8.2's "for each unsupported or missing assessment" as
covering the empty set, with M8a's observed wrapper and `matrix.rs`'s binary
pin of both SI2 causes; or (b) an init test seam, which ruling 6 refuses.

**F6, assumption on private types.** Ruling 8's "one pin per module" is read
as one literal per production home. A variant an integration test cannot
name, because its type is crate-private, keeps one literal at the binary edge
beside its unit-test home.

**Observed, no defect.** A plan rewritten after sealing and left rewritten
makes the engine's settlement refuse with "the attempt's retained responses

not bound to this attempt", and the run prints no state. Row 2's test puts the
