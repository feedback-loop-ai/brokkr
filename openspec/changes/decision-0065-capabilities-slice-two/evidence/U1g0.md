## What changed

U0 measured spark-glm only. U0c's `spark` cells S01–S03 are partial: the
model server was down, so no tool call was observed. The operator ruled that
`spark` is not qualified. A dsh launch pinned to `spark/...` now refuses its
tool servers with `provider 'dsh' has no measured strict MCP configuration on
route 'spark'`, even when it carries its route overlay. The route check runs
in the same place as before, after the shapes.

`StrictCause` is a public `thiserror` enum with two variants.
`Unsupported { provider, reason }` renders "provider '<provider>' cannot
exclude ambient MCP configuration (<reason>)" and
`Unmeasured { provider, shape }` renders "provider '<provider>' has no
measured strict MCP configuration for '<shape>'". These are SI2's two site
texts, word for word. `McpRefusal`'s two former variants of the same name
became one `#[error(transparent)] Strict(#[from] StrictCause)` variant, so
the launch refusal reads exactly as before after the driver's prefix. The
provider is a `String`, because U1g1 carries provider names from bundle
data.
