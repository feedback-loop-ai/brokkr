The helper validates no more of the JSON number grammar than this: it is applied only to tokens the parser has already read as numbers, so malformed numbers are refused by the parser before any signature is taken. This corrects, not preserves, the shipped predicate, which accepted any mantissa containing a zero digit (`10e-400`, `0.1e-400`) as a zero spelling. Adapt the direct `zero_number_token` calls in the tests named in 4.3.
