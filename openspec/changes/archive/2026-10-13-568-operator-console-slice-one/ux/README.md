# Step-1 UX reference

These are the step-1 boards from the "DSH Operator Console" design canvas
(page **Step 1 · feasible today**, 2026-10-13), saved as static HTML mockups.
They are the reference for layout and copy. Run titles, rule names and numbers
are sample data. The `<x-dc>` wrapper and `support.js` belong to the canvas
tool and are not part of the design.

| File | Board |
|---|---|
| `S1Realms.html` | All realms: cards, queue with admission verdicts, Ask Brokkr, Muninn's last review |
| `S1Run.html` | One realm: run list, run graph, decision card with admitted commands and "not available yet", timeline, Ask about this run |
| `S1Decisions.html` | Clarify questions, out of attempts, quiet run; the four command outcomes |
| `S1Analytics.html` | Analytics limited to recorded facts |
