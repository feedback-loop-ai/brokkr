## A behaviour this changes with the fence standing

The unit's proof asks that, with the fence standing, nothing else changes.
One thing does, through code already on main, without a production edit
here. brokkr-protocol's `dsh_served` (`served_home.rs`) serves a dsh launch
from an engine-only home wherever the driver admits its shape, and from the
operator's own dsh home where it does not, while the fence stands. The
replacement's verdict was `unmeasured`, so a resumed dsh launch (the
replacement a rejoin offer launches) was served from the operator's home,
while a cold one was already engine-only. Now the verdict is `measured`, so
on Linux both launches are served from the engine-only `DSH_HOME`, which
reads a key from the launching environment alone. `brokkr doctor` and the
end of `brokkr init` now print one engine-only home line for a dsh scaffold,
where before they printed a two-state line ending "serves a resumed launch
from the operator's own dsh home … while the driver does not admit its
replacement shape". This is the served-home model's ruled behaviour for a
measured shape (#717), and the shape pass 8 measured. It is recorded here
because it moves a live launch, not only a record. No guide transcribes the
old line (`git grep` found none).

## Finding: the lifted fence still refuses every dsh work seat

Past a lifted fence, SI2 judges a work site cold, as its replacement, and as
each resume shape its adapter declares under the same hands
(`strictness` in `crates/brokkr-runtime/src/bundle/mcp.rs`). dsh declares
one, `headless-work` (`resume` in `adapters/dsh.json`, status `unmeasured`),
and no `mcp.shapes` entry measures it. With this unit, the in-crate lifted
compile of the shipped-facts scaffold refuses "provider 'dsh' has no measured
strict MCP configuration for 'headless-work'", where it refused
`'replacement'` before (the `mcp_tests` row above). The six recipes' records
carry the same `headless-work none absent`. So U9b1's next run will meet this
cause on every dsh work seat, unless a later unit measures or rules dsh's
headless-work shape. This unit does not touch it: it is another shape, and
the controller's framing says any other axis or field comes back to the
operator.
