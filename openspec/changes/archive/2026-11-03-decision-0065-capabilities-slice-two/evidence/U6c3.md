# U6c3: the shared namespace builder extracted (tasks 28.5–28.6)

Run `0065-slice-two-unit-u6c3-see-the-861e7aa0` built U6c3 on branch
`s2/U6c3` from main at `cb553b47`. The unit changed exactly the row's two
production files: `crates/brokkr-protocol/src/hands.rs` and the new
`crates/brokkr-protocol/src/hands/namespace.rs`. No contract, fixture,
policy table, reference schema, extension, adapter or agent file moved, and
no MCP grant was touched, so the U9 fence stands.

## What changed

`hands/namespace.rs` (173 lines) is registered in `hands.rs` as a private
`mod namespace;`. It holds what every box shares, and nothing that only the
workspace box needs:

- `Namespace::open(network)` builds bubblewrap's isolation flags, the
  `--unshare-net` that applies unless the spec grants network, `--clearenv`
  with `BROKKR_HANDS_BOX`, `/proc`, `/dev`, the skeleton directories, and
  the read-only host toolchain. It iterates `HOST_TOOLCHAIN_BINDS`, and that
  table's single definition stays in `hands.rs`.
- `Namespace::identity(etc)` writes the generated `passwd`, `group`, `hosts`
  and `nsswitch.conf` and binds them read-only over `/etc`.
- `mount`, `mount_in_place`, `tmpfs`, `overlay` and `setenv` serialize the
  mounts and environment. The closed `Mount` enum replaces the four
  bubblewrap bind flags that `box_argv` had spelled as strings.
- `enter` closes the argv with `--chdir`, `--` and the command.

`namespace_path` and `namespace_join` moved with the builder, because they
render host paths as paths inside the box. `hands.rs` re-exports
`namespace_join` as `pub use`, so the public API is unchanged
(`quality/ratchet.sh api`: "public API holds"). `overlay.rs` still imports
`super::namespace_path` through the parent's private `use`, and the file is
unmodified.

`box_argv` keeps its signature and its two callers. `execute_in` passes
`OverlayWrites::Session` and `run_boxed_in` passes `OverlayWrites::Ram`
plus its own read-only bind. The function now opens a `Namespace` and
keeps the workspace orchestration itself: the absolute workdir, the
private home and tmp mounted before the worktree, the bundle, the git
common directory with its hooks tmpfs and read-only config, the declared
binds with masks, and `overlay_argv`'s session/RAM difference. The
environment table moved unchanged into the private
`box_environment(spec, home)`. That brought `box_argv` under clippy's
100 lines, so its `#[expect(clippy::too_many_lines)]` is removed, along
with its entry in `quality/too-many-lines.txt`. `hands.rs` went from
1,267 to 1,170 lines. The unit adds no server profile, server variant or
public item.

## Tests

The owning suite is `crates/brokkr-protocol/src/hands/tests.rs`, which
grew from 1,464 to 1,595 lines. Two tests are new:

- `the_workspace_and_exec_argv_keep_their_exact_order_and_identity` pins
  the whole argv with `assert_eq!` for two configurations. The workspace
  box has `Session` overlays and no network. The exec box is networked,
  has `RAM` overlays and an appended read-only self bind, as
  `run_boxed_in` adds it. Both configurations have a git worktree outside
  the workdir, a bundle, an overlay with a mask and `ro`/`rw` binds. The
  pinned argv covers every flag, mount, `--setenv` pair and the `--chdir`
  tail, in order, on a canonicalised temporary root. This test was
  written first and passed on the code before the extraction
  (`cargo test -p brokkr-protocol --lib hands::tests::the_workspace_and_exec`:
  1 passed). It then passed unchanged after the extraction, which shows
  exact argv, environment and mount-order parity.
- `the_generated_identity_is_the_engines_own_and_resolves_from_files`
  calls `Namespace::identity` directly and asserts the exact bytes of all
  four generated files.

The existing relative-workdir control in
`the_namespace_is_built_from_an_empty_root_and_binds_what_the_spec_names`
passes unchanged: `.` is bound and entered at its absolute path, and the
empty path is refused. The #504 lifetime controls also pass unchanged.
`an_exec_box_writes_its_overlays_to_ram` covers the RAM overlay through
`run_boxed_in`, and the session overlay surviving between calls of
`the_box_hides_the_host_and_holds_the_worktree` covers the workspace
side through `execute` → `execute_in`. No test moved.

This host built real bubblewrap namespaces, so no boundary proof was
skipped. A `--nocapture` run of the runtime owning suite
`crates/brokkr-runtime/src/engine/boundary_tests.rs` printed no
`skipped:` line, and its 41 tests passed.
