# Decision 0065, slice one — implementation tasks

Execute the numbered tasks in order against [proposal.md](proposal.md), the
six [spec deltas](specs/) and [design.md](design.md), especially Decisions
D2–D10. Each checkbox names its owning requirement and its completion proof.
All boxes are initially unchecked: this tasks-phase draft implements nothing.
Tick a task only after its stated work and verification are complete.
Capability refusal tests compare entire diagnostics and notices; `is_err()`,
status-only or substring assertions do not satisfy these proof obligations.

Accepted 0065 and the controller's admitted slice govern this breakdown.
The design's open questions are explicitly owned measurement gaps, not
unresolved choices about what to build. No upstream artifact change is needed.
Only the realm grants; this repository's v3 map continues granting nothing.
All production implementation stays in Rust under `crates/`. New test inputs
belong in temporary directories or the owning suite, never `fixtures/`.

Do not modify existing contract versions, `policy/phase-machine.json`,
`policy/schemas/`, `fixtures/`, `reference/`, `extensions/`, the event envelope
or the issue-226 task ledger. Preserve historical evidence. Slice two owns MCP
brokers, gate capability policy, checkpoint enrichment and retained results;
slice three owns comparisons and `capabilities: equal`. This slice defines
MCP data and refuses its use. Linux and macOS are the only supported hosts.
Additional semantic rulings require a separate proposed decision; do not amend
accepted 0065 through an implementation exception.

Task-phase validation: all 43 tasks cite requirements and state verification;
the links cover all 35 requirements in the six deltas. Strict change validation
and strict all-item validation passed (16 items, zero failures). OpenSpec
reports planning complete; implementation remains unstarted. Formatting,
clippy, both workspace suites, all seven crate suites and self/verify compiles
were attempted through workspace hands but could not start because Cargo is
absent from PATH; exact coverage stopped at Cargo with exit 127. No Rust,
compile, coverage or live-provider pass is claimed by this draft.
