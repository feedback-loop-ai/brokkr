# v0.11.0 — transcripts everywhere, realms that cross, and Linux plus macOS

This release makes every provider's session readable on every surface,
lets a world of several repositories record what crosses between them, and
narrows the supported hosts to Linux and macOS. It includes the changes
merged since [v0.10.0](https://github.com/feedback-loop-ai/brokkr/releases/tag/v0.10.0).

## What changed

- **Read every transcript.** Claude, Codex and DeepSeek-harness sessions are
  readable from the CLI, the TUI and the browser console, and the transcript
  projector is bounded — 144 MB down to 6.8 MB on the measured case.

  [#298](https://github.com/feedback-loop-ai/brokkr/pull/298),

  [#278](https://github.com/feedback-loop-ai/brokkr/pull/278)
- **Realm crossings.** A world of two repositories is proven, and crossings
  between realms are named, loaded, recorded in the run manifest and verified
  across runs, with a readout.

  boundary work: the Seatbelt boundary's startup is measured and ledgered.
  It does not yet box a seat.

  any work; a launched session's root is confirmed before anything is

## Windows is no longer a host

Decision 0063: the supported hosts are Linux and macOS, and WSL2 is Linux.
**This is the first release without a Windows archive.** The
`x86_64-pc-windows-msvc` build, its binstall override and the Scoop channel
are gone; the Scoop bucket is retired at 0.10.0. On Windows, install inside
WSL2 through any Linux channel.
[#308](https://github.com/feedback-loop-ai/brokkr/pull/308),
[#309](https://github.com/feedback-loop-ai/brokkr/pull/309)

## Accepted, not yet in this build

Two decisions were accepted in this cycle and are **not built in 0.11.0**:

- **Decision 0064 — a run says how it ended.** Typed endings beside the
  status. Runs still end `completed` or `stopped`.
- **Decision 0065 — capabilities are the realm's to grant.** Until it lands,
  a Codex seat launched by this release **can use Codex's own server-side web
  search**, which a boxed seat's `network: false` does not stop. For a private
  repository, add `-c web_search="disabled"` to a Codex seat's driver
  arguments.

## Upgrade and compatibility

New `dialect.v3`, `realms.v5`, `run-manifest.v10` and `seat-record.v5` files
sit beside their earlier contracts; no earlier frozen bytes changed. The
version bump and the roster move change compiled manifest identities; use the
engine's normal resume comparison and refusals when bringing a run across
versions. The binary remains `brokkr`, with Rust 1.88 as the minimum build
version. Verify a download against `SHA256SUMS` and its build provenance with
`gh attestation verify <asset> -R feedback-loop-ai/brokkr`.
