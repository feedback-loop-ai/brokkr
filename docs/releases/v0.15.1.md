# v0.15.1: the shipped roster moves to Sol 6.2, Astra 6.2, Terra 6.1 and Fable 5.2, dsh 0.2.2-rc.5 is a measured hands release, and a damaged journal is one refusal that names the file

v0.15.1 is a patch on
[v0.15.0 “Gullinbursti”](v0.15.0.md). It carries the fixes that were in
flight when 0.15.0 shipped, and the changes merged beside them. It
includes everything merged since
[v0.15.0](https://github.com/feedback-loop-ai/brokkr/releases/tag/v0.15.0).

It needs no migration. Read
[Upgrade and compatibility](#upgrade-and-compatibility) if you keep your
own adapter files, pin a model id in a recipe, or match a journal read's
error by its text.

## What changed

- **The shipped model roster moves to the latest models
  ([#1155](https://github.com/feedback-loop-ai/brokkr/issues/1155),
  [#1165](https://github.com/feedback-loop-ai/brokkr/pull/1165)).**

  | Alias | Was | Now |
  |---|---|---|
  | `sol` | gpt-6.1-sol | gpt-6.2-sol |
  | `astra` | gpt-6-astra | gpt-6.2-astra |
  | `terra` | gpt-5.6-terra | gpt-6.1-terra |
  | `luna` | gpt-6-luna | gpt-6-luna |
  | `fable`, `fable-tallied` | claude-fable-5-1 | claude-fable-5-2 |

  - **Where:** the `models` maps of `adapters/codex.json`, `claude.json`
    and `lanetally.json`, and the copies `brokkr init` writes. The shipped
    recipes' inline pins move with them (preflight, review-first, standby
    and wager-harness).
  - **What stays:** aliases, judges, efforts, flags, hands and tool
    permissions.
  - **Decisions 0031, 0041 and 0045** each record the new mapping in a
    dated addendum; their alias rulings stand.
- **dsh 0.2.2-rc.5 is a measured hands release with its own composed set
  ([#1158](https://github.com/feedback-loop-ai/brokkr/issues/1158),
  [#1163](https://github.com/feedback-loop-ai/brokkr/pull/1163)).**
  - **Before, Brokkr refused rc.5** for every hands seat. npm's `latest`
    dsh is 0.2.2-rc.5, and `Release::named` admitted only 0.2.1-rc.2,
    0.2.1-rc.3 and 0.2.2-rc.1.
  - **Its own release.** rc.5 is matched whole. Its judge admits
    0.2.2-rc.1's set plus rc.5's measured delta: the `agent-team` host
    row, the `tool-agent-team` row, and `deepseek-account` under its new
    package.
  - **Fail closed on the new surface.** The hands overlay writes
    `tool-agent-team` disabled on rc.5, and a composed tree that enables
    it is refused.
  - **The measurement** is in
    [the dsh hands record](../evidence/adapters/dsh-hands-0-2-2.md). 0.2.1
    and 0.2.2-rc.1 are unchanged.
- **A damaged journal is one refusal that names the file and the way back
  ([#1000](https://github.com/feedback-loop-ai/brokkr/issues/1000),
  [#1143](https://github.com/feedback-loop-ai/brokkr/pull/1143)).**
  - **The sentence.** A journal Brokkr cannot read prints as one
    sentence: the journal's path, the cause, that nothing was read from
    it, and where to restore it from. Before, every read surfaced bare
    SQLite or serde words with no path.
  - **Where.** `runs`, `inspect`, `export`, `seats`, `watch` and `tui`
    print it and exit non-zero. `watch` used to read damage as transient,
    and now ends at once.
  - **The fleet listing** quarantines a run whose envelope is not JSON,
    and lists the healthy runs beside it.
  - **Brokkr reports damage and never repairs it** (decision 0001). The
    journal guide's new section, "A damaged journal", is the one the
    sentence names.
- **One home for the payload shapes the sweep reads
  ([#430](https://github.com/feedback-loop-ai/brokkr/issues/430),
  [#1160](https://github.com/feedback-loop-ai/brokkr/pull/1160)).**
  `brokkr-core` gives an effect's id, and an operator command's id and
  word (`accepted_command`, `operator_command`, `succeeded_effect`).
  Eligibility's own decodes go.

## Fixed

- **The sweep keeps an undecodable operator command's rows for a reason
  of its own,** "an operator command after its end does not read"
  ([#1160](https://github.com/feedback-loop-ai/brokkr/pull/1160)).
- **`brokkr dispatch`'s `started:` line names the driver's log,** and the
  standing loop's sleep wakes on the signal rather than on a 50 ms beat
  (decision 0110's lows,
  [#1152](https://github.com/feedback-loop-ai/brokkr/pull/1152)).
- **Every match over `EventType` in the view names each arm,** so a new
  event type does not compile until its readout is decided
  ([#950](https://github.com/feedback-loop-ai/brokkr/issues/950),
  [#1153](https://github.com/feedback-loop-ai/brokkr/pull/1153)).
- **The required RustSec audit is the pinned `cargo audit`'s own exit
  code,** in CI and in the release admission. It no longer fails a clean
  audit on a check-run API error
  ([#1113](https://github.com/feedback-loop-ai/brokkr/issues/1113),
  [#1150](https://github.com/feedback-loop-ai/brokkr/pull/1150)).
- **The driver's reaper tests are bounded throughout.**
  - The single-orphan test sees its orphan adopted before it sees none
    left.
  - A rerun past its deadline is killed, reaped and drained in time.
  - A launched box releases its hold with its own wait.

  These are #1133's follow-ups
  ([#1154](https://github.com/feedback-loop-ai/brokkr/pull/1154)).
- **The reaped-pid test fixture is bounded by one patience,** and a reap
  first seen after the deadline never counts as within it
  ([#1160](https://github.com/feedback-loop-ai/brokkr/pull/1160)).
- **The flake's digests catch up with v0.15.0**
  ([#1151](https://github.com/feedback-loop-ai/brokkr/pull/1151)).
- **The shard runner's `--help` names the pinned nightly's coverage
  layout** beside `deps`
  ([#1129](https://github.com/feedback-loop-ai/brokkr/issues/1129),
  [#1162](https://github.com/feedback-loop-ai/brokkr/pull/1162)).

## Upgrade and compatibility

- **Adapter files you keep yourself are not touched.** Only the shipped
  adapters and what `brokkr init` writes move to the new model ids. A
  realm or recipe pinning `gpt-6.1-sol`, `gpt-6-astra`, `gpt-5.6-terra` or
  `claude-fable-5-1` by its concrete id keeps it. Such a gate pin must
  still map to a judge alias in its driver's adapter, or `compile`
  refuses it, as before.
- **dsh.** A hands seat on dsh 0.2.2-rc.5 is now admitted. 0.2.2-rc.2,
  rc.3 and rc.4 stay unmeasured and refused. You need not move from
  0.2.1-rc.2 or 0.2.2-rc.1.
- **A damaged journal's error text changed.** Anything matching the old
  bare SQLite or serde words for a journal read now sees the one sentence
  above, and a non-zero exit from `watch` where it used to keep polling.
- **The public API** gains `brokkr_core::accepted_command`,
  `operator_command` and `succeeded_effect`. Nothing is removed.
- **Contracts:** unchanged. The engine version reads 0.15.1.
