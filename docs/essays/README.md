# Essays

The paradigm, argued in long form. Every claim in these essays is
checkable against this repository's own history — the
[decision record](../decisions/), the [evidence shelf](../evidence/),
and the journals they cite are the footnotes.

| Essay | One line |
|---|---|
| [The Model Is a Detail](the-model-is-a-detail.md) | Determinism belongs in control flow; stochastic execution belongs in leaf effects — and any feedback loop that can be specified deterministically must be. |
| [Decisions as Code](decisions-as-code.md) | ADRs with teeth, policy with a memory: deliberate → rule → encode → enforce → evidence → amend. |
| [The Lore](the-lore.md) | Why a mythology layer is an engineering decision: a name that carries its lesson is documentation with a recall rate — if, and only if, the fun is under law. |
| [The Machine That Argued With Itself](the-machine-that-argued-with-itself.md) | Self-review is theater until structure makes it argument: fresh contexts, typed verdicts, real consequences, bounded returns, and a judge that is not a model. |
| [The Wager](the-wager.md) | Fair model comparison is an architecture property: two crews, one commission, two confessions from the referee — and the gods judged the gifts without asking which dwarf made them. |
| [One Job, Three Hires](one-job-three-hires.md) | A lifecycle phase held by a model is a job in the ordinary sense — job description, price tag — and what a delivery costs is set by how the jobs are cut and described, not by who is hired into one. |

## The reading path from the determinism laws

The paradigm behind these laws is argued in long form in
[the essays](./): *[The Model Is a Detail](the-model-is-a-detail.md)*
(why the model belongs in leaf position, with this repository's own
history as the receipts) and
*[Decisions as Code](decisions-as-code.md)* (the
deliberate → rule → encode → enforce → evidence → amend lifecycle the
[decision record](../decisions/) lives by), and
*[The Lore](the-lore.md)* (why the
[Edda](../lore/edda.md) is an engineering decision, not decoration),
*[The Machine That Argued With Itself](the-machine-that-argued-with-itself.md)*
(five arguments from the journals, and what makes them argument
instead of theater), *[The Wager](the-wager.md)* (two
crews, one commission, and why fair model comparison is an
architecture property), and
*[One Job, Three Hires](one-job-three-hires.md)* (a phase
held by a model is a job with a description and a price tag; three
hires into one job, thirty to one on price, the same gates for all).
