# The docs lane's tests (#1295): what a pull request that changes only
# documentation runs in place of the whole matrix, through
# `scripts/docs-lane.sh run`. One entry a line:
#
#   <package> <target> <filter> <file>...
#
# The target is `lib`, a package's library tests, or `test:<name>`, as in
# scripts/test-shards.sh (`test:it` is brokkr-cli's one integration binary),
# and the filter a module path libtest runs whole. The files are the ones
# that filter runs, a directory ending in `/`: the classifier counts a page
# they name as documentation, which a page named anywhere else is not.
# crates/brokkr-cli/tests/contributing/docs_lane.rs holds the list complete:
# a test file that reads documentation it does not name must be here.
